## [v5.0] - 2026-10-17

- Фаза 22: пять read-only git-инструментов в MCP-сервере проекта; гейты путей и ссылок, хелперы усечения; скелет MCP-сервера проекта, проверки запуска и ограниченный git-раннер; документация по встроенным MCP-серверам.
- Фаза 23: таблица HelpConfig, строительные блоки /help и фильтр MCP на уровне сервера; маршруты GET/PUT /api/v1/help/config; /help-ретрив без гейта и проверка цитат с учётом инструментов; общий хелпер stream-and-tool-rounds; секция настроек /help и бейдж базы знаний; отображение метки ответа /help, предупреждений и временного уведомления; /help через WebSocket и HTTP-эндпоинт чата; драйвер контрольных прогонов /help на изолированной копии, замер порога и фиксация контрольного набора; команды judge и summary в драйвере контрольных прогонов.
- Фаза 24: таблицы ReviewConfig и ReviewCodeIndex; чанкер кода для индекса ревью; чтение всего Pull Request из GitHub MCP-сервера; CI-скрипт ревью PR с построением комментария; workflow ревью PR на self-hosted runner; промпты ревью, разбиение бюджета, хелперы запроса, разбора и санитизации; run_review с ретривом по базам, вызовами модели и слиянием; инкрементальная база знаний кода из git-объектов; shell-free чтение базовой ветки для индекса кода; сервис ревью с разрешением настроек и produce_review; маршрут ревью, маршруты настроек и маршруты индекса кода; секция Review Pull Request в окне настроек; контрольный скрипт прогона тестовых PR на GitHub и зафиксированный набор тестовых PR; таблицы DeepSeek judge и отчётов для контрольного набора ревью.
- Фаза 25: общий механизм command-turn и фасад help_command; read-only MCP-сервер support desk и seed-данные; русский FAQ поддержки с секциями «сначала симптом»; таблица SupportConfig, грамматика /support, уведомления и инструменты; история, сообщения, payload, prepare и finalize для /support; прямой поиск поддержки, data fence и запрос ретрива; маршруты настроек /support; /support через WebSocket и HTTP-эндпоинт чата; секция настроек /support и отображение метки, заметок и заголовка уведомления в чате; ретрив-проба /support с протестированными хелперами решений; e2e-скрипт /support на изолированной копии; документация /support в API-спецификации, архитектуре, README, руководстве пользователя и руководстве по тестированию.
- Фаза 26: read_file, search_text и find_usages в git MCP-сервере; цветной diff в карточках вызовов инструментов; воспроизводимый скрипт целевого прогона с логом и патчем; write gate, флаг --allow-write, write_file и edit_file; драйвер сценариев для отчёта Day 34; документация ассистента файлов проекта; демо-видео Day 34.
- Фаза 27: грамматика /release, типы плана и контракт кадров; логика версий, парсеров, фильтрации и группировки релиза; промпты релиза, парсеры вывода, проверка покрытия и секции; флаг --allow-release с release_context и release_range_commits; инструменты коммита changelog, аннотированного тега и push; инструмент github_create_draft_release; обёртка release llm для решения по changelog и версии; планировщик релиза с внедряемым вызовом инструментов; tool_frames и ReleaseMcp с карточками инструментов; машина состояний шага confirm_plan; карточка плана релиза с валидацией версии и подтверждением; обновление карточки релиза по кадрам прогресса и результата; /release через WebSocket с состоянием плана и очисткой; e2e-скрипт релиза с preflight безопасности и хелперами настройки; четыре e2e-сценария релиза, проверка changelog по коду и файл результатов; опция --model и контрольные сценарии на deepseek-flash.
- Быстрые задачи: кнопка выбора папки в настройках ревью; сессионный маршрут выбора папки с диалогом PowerShell; показ существующих файлов в модальном окне добавления файлов; GET-эндпоинт списка файлов базы знаний.
