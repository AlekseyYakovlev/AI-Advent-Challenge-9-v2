# Phase 18 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope.** This phase is mostly backend/network. The UI surface is exactly three touchpoints; no new screens, no new pages, no new design tokens:

1. A read-only "Сеть" section in the existing Settings modal (`#settings-modal` in `ui/static/index.html`) — decisions D-11, D-12.
2. The `run.py` console output in LAN mode (address list + exposure warning) and the invalid-`BIND_HOST` error — D-08, D-09, D-10, D-15.
3. Confirmation that the frontend host/WebSocket derivation needs no change (`window.location.hostname`, `ui/static/app.js:3-5`, `login.html:41-42`).

Everything else in `ui/static/` is locked as-is.

## Settings Modal — "Сеть" Section Contract

**Placement.** New `<section id="network-section" class="border-t border-slate-700 p-5 space-y-3">` inside `#settings-modal`'s card, as a sibling of `#mcp-section` (after the existing "Провайдеры LLM" section, i.e. last section; assumption: network info is least-frequently used). Heading: `<h3 class="text-lg font-semibold">Сеть</h3>`. No form, no Save button — read-only.

**Data source.** Fetched from the new authenticated REST endpoint (D-12) each time the modal opens (cookie session via existing fetch helper). The shape is the planner's call but must expose: `mode` (`loopback` | `lan`), and `addresses` (list of URL strings, same list `run.py` prints — single source of truth). The UI renders `addresses` verbatim and does not compute addresses client-side.

**States.**

| State | Rendering |
|-------|-----------|
| Loading | Status line `text-sm text-slate-400`: "Загрузка…" |
| Loopback | Status line `text-sm text-slate-300`: "Доступен только на этом компьютере". Hint `text-xs text-slate-500`: "Чтобы открыть доступ из локальной сети, укажите BIND_HOST=0.0.0.0 в файле .env и перезапустите приложение." (`BIND_HOST=0.0.0.0` in `<code class="font-mono text-slate-300">`). No address list. |
| LAN | Status line `text-sm text-yellow-500`: "Открыт в локальной сети". Hint `text-xs text-slate-500`: "Нажмите на адрес, чтобы скопировать ссылку. Соединение не защищено HTTPS — не используйте в общедоступных сетях." Then the address list (below). |
| Fetch error | `text-sm text-red-400`: "Не удалось получить сведения о сети. Попробуйте открыть настройки ещё раз." (red used only for this error text; consistent with existing error copy). |

**Address list (LAN state).** `<ul class="space-y-2">`; each item is a `<button type="button">` (keyboard-focusable, full width, left-aligned): `w-full text-left rounded-lg bg-slate-800 border border-slate-700 hover:border-indigo-500 px-3 py-2 text-sm font-mono focus:outline-none focus:ring-2 focus:ring-indigo-500 transition`. Content is the URL as plain text set via `textContent` (never `innerHTML`; if any HTML is ever needed use `DOMPurify.sanitize()`). `aria-label`: "Скопировать ссылку {url}". Order: non-loopback IPv4 addresses, then `http://<machine-name>:8000`, then `http://127.0.0.1:8000` (same order as the console, D-08).

**Copy interaction.** Click copies the full URL. Reuse the exact pattern of `copyMcpToolName` (`app.js:2135-2154`): try `navigator.clipboard.writeText`, fall back to the hidden-`textarea` + `document.execCommand('copy')` path (required: the modal is typically opened over plain HTTP via a LAN IP, a non-secure context). Implement as a shared helper or a sibling function `copyNetworkAddress(url)`. Feedback via `showToast`: success `Скопировано: {url}` (type `success`); failure `Не удалось скопировать в буфер обмена` (type `error`). No inline checkmark state change.

**Accessibility.** Section heading is an `h3`; status line has `role="status"`; buttons are native `<button>`; contrast: slate-300/yellow-500 on slate-900 meets AA for 14px text (yellow-500 on slate-900 ≈ 8:1; slate-500 hint text at 12px is the existing project convention and is kept for consistency).

**Frontend host derivation (no change).** `AGENT_BASE`/`WS_BASE` already use `window.location.hostname`; they continue to work when the UI is opened as `http://192.168.x.x:8000` or `http://my-pc:8000`. `AGENT_PORT = 8001` stays hardcoded. Do not add host configuration UI. The existing connection/origin error states (WebSocket error toasts, login error) are reused unchanged; no new "origin rejected" screen is added (a foreign-origin rejection is a security block, not a user flow).

## Console (run.py) Output Contract

All console text is English (matches existing `run.py`). ASCII only (Windows console safe, avoid the em-dash in new lines; the pre-existing bootstrap banner is left untouched).

**Loopback mode (BIND_HOST unset/empty/`127.0.0.1`/`localhost`):** output byte-for-byte unchanged (D-10): `Starting UI on http://127.0.0.1:8000`, `Agent will be auto-started on port 8001`, `Press Ctrl+C to stop.`

**LAN mode (`0.0.0.0`):** printed after bootstrap-admin banner (if any) and replacing the single `Starting UI on ...` line. Layout (60-char `=` rules, same as `run.py:50-55`):

```
============================================================
WARNING: LAN mode is ON (BIND_HOST=0.0.0.0)
The app is reachable by everyone on your network.
Traffic is plain HTTP (no HTTPS): do not use on public networks.
To go back to local-only access, remove BIND_HOST from .env
or set BIND_HOST=127.0.0.1, then restart.
============================================================
Starting UI on:
    http://192.168.1.23:8000
    http://my-pc:8000
    http://127.0.0.1:8000
Agent will be auto-started on port 8001
Press Ctrl+C to stop.
```

Rules: one URL per non-loopback IPv4 of an active interface, then machine name, then loopback (D-08); 4-space indent for URLs; use the same address-builder function the REST endpoint uses. Exact wording above is the recommended default (Claude's discretion per CONTEXT); the five facts (reachable by everyone on the network, plain HTTP, not for public networks, how to revert, addresses) are mandatory.

**Invalid BIND_HOST (D-15):** to stderr, no traceback, exit code 2, before port cleanup and admin bootstrap:

```
ERROR: invalid BIND_HOST value '192.168.1.23'.
Accepted values:
    127.0.0.1  (or localhost, or unset/empty)  - local access only (default)
    0.0.0.0                                   - reachable from the whole local network
Binding to a specific LAN IP or '::' is not supported: use 0.0.0.0.
Fix BIND_HOST in .env and start again.
```

The `{value}` is echoed with `repr`-style quotes after whitespace trimming.

## Assumptions (non-interactive session)

- "Сеть" section is placed last in the Settings modal and fetched on every modal open (no caching).
- Loading, fetch-error and empty-address copy are defaults chosen to match existing Russian copy tone; the planner may adjust wording but not structure.
- `text-red-400` is used for the single fetch-error line only; `yellow-500` is reused from the existing context-length warning for the LAN notice.
- No in-app toggle for LAN mode: changing `BIND_HOST` is `.env` + restart only (matches CONTEXT domain boundary).
- The warning banner and error message wording are recommendations; mandatory facts are listed above.
