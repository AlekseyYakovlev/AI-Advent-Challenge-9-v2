<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user message / assistant answer -> title prompt | Untrusted text is placed into an LLM prompt |
| LLM output -> chat.title -> browser | Untrusted model output is stored and later rendered in the sidebar and header |
| Agent -> /ws/events | Per-user data (a chat title) leaves the process |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
