## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WebSocket client → `_handle_chat_message` | Authenticated, chat-ownership-gated at accept time (Phase 1); message content is user-controlled |
| LLM response → tool dispatch → DB | Model-generated tool calls trigger durable writes within the user's scope |
| DB memory rows → outbound LLM request | Stored memory is re-sent to the LLM provider on every turn |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-14 | Tampering | concurrent turns racing memory writes | mitigate | Dispatch runs inside the existing `chat_locks[chat_id]` lock and the same session as the triggering message; no background task — locked by the `async_session_factory` count and gather/create_task grep gates |
| T-02-15 | Elevation of Privilege | write scoping | mitigate | `dispatch_tool_calls` receives `chat.user_id` resolved server-side from the chat row, never from the client message or the model's arguments; tools are disabled entirely when `chat.user_id is None` |
| T-02-16 | Information Disclosure | memory injected into outbound LLM requests | accept | Inherent to read-injection (02-RESEARCH.md discretion call A3); memory is per-user and the deployment is local-first with the user's own configured backend |
| T-02-17 | Denial of Service | unbounded tool-call loop | mitigate | Exactly one tool round per turn — the follow-up `stream_chat` is called without `tools`, so the model cannot chain another round |
| T-02-18 | Denial of Service | memory inflating the context window | mitigate | Injected memory flows through the existing `build_system_prompt`→`build_llm_context`→`compute_chat_stats` path, so the 75%-of-`context_length` trigger and the `no_compression` `ContextOverflowError` guard both account for it |
| T-02-SC | Tampering | npm/pip installs | mitigate | Not applicable — zero new packages (02-RESEARCH.md Package Legitimacy Audit); no install task in this plan |
</threat_model>
