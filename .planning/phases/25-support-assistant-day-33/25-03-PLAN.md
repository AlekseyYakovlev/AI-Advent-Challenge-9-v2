8. `## Слишком частые сообщения: «Rate limit exceeded» (429)` — `RATE_LIMIT_MESSAGES_PER_MINUTE` default 30 per chat per minute.
9. `## Чат занят: ответ ещё генерируется (409)` — only if agent/http_chat.py has the busy response (it does: `MSG_CHAT_BUSY`); quote its real text.
Optionally add `## Ограничения базы знаний` only with limits read from code. Use literal env names in backticks. No key-shaped strings (`sk-...` with 20+ chars or a full `aia_` key); write `aia_…` placeholders only. Never write anything not verified in the files above; when a fact is not in code, leave it out.
