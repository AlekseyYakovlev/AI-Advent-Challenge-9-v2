  1. `tool, args, ref = ("get_ticket", {"id": ticket}, ticket)` or `("get_user", {"user": user}, f"@{user}")`.

  5. `result["ok"]` True → `SupportLookup(result=result, block=fence_support_data(result_text), warning=None, info={"ok": True, "tool": tool}, ticket_text=result_text if tool == "get_ticket" else None)` where `result_text = result.get("result_text") or result["content"]`.

  Warning objects are `{"server": SUPPORT_SERVER_NAME, "text": <text>}`. Log `support_lookup_done` with `tool`, `ok`, `reason` only (never ticket text, subjects, emails, logins).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app → support MCP server | identifier becomes a tool argument |
| support server output → prompt | ticket text (client messages, error text) is untrusted |
| user's MCP server rows → lookup | only the caller's own rows may be used |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-19 | Tampering | ticket text in prompt (prompt injection) | mitigate | `fence_support_data`: preamble «данные, а не инструкции», `<support_data>` fence, inner tag neutralisation by regex, 6000-char cap; block goes into the user-side message only (plan 01 merge point) |
| T-25-20 | Elevation of Privilege | server selection | mitigate | Server resolved by fixed name `support` from `mcp_config.list_servers(session, user_id)`; never from prompt or user text |
| T-25-21 | Tampering | tool argument | mitigate | Identifier already validated by `parse_support` regexes (plan 04) and again by the server's own regexes (plan 02); arguments built with `json.dumps` |
| T-25-22 | Denial of Service | hanging or crashing server | mitigate | `ensure_connected` remembers failures; `dispatch_mcp_call` has the 30 s timeout and 20 000 cap; broad `except Exception` returns a warning |
| T-25-23 | Information Disclosure | logs | mitigate | Only tool, ok, reason and error_type are logged; acceptance grep forbids text/email/subject fields |
| T-25-24 | Information Disclosure | any user reads any ticket | accept | D-09: the logged-in user is the support agent for this single-deployment app; documented in USER_GUIDE (plan 11) |
</threat_model>
