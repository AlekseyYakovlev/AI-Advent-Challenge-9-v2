## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model answers and quotes -> judge prompt | untrusted text is embedded in a prompt sent to DeepSeek |
| .env secret -> judge script | the DeepSeek key is used for outbound requests |
| raw eval data -> rendered tables | the tables must reflect the records |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-20 | Tampering | prompt injection through answer or quote text in the judge prompt | mitigate | inputs wrapped in tags after `_neutralise`; the system prompt declares tag contents as data |
| T-16-21 | Information disclosure | DeepSeek key | mitigate | key read from settings only; never printed, logged or written; grep gate; `--check` unchanged |
| T-16-22 | Repudiation | evaluation theater: auto quotes or fuzzy matches folded into "verified", empty answers counted as "no quotes", hidden false refusals | mitigate | separate counters for exact / fuzzy / unverified / auto, kind `empty` as its own category, false refusals listed by question id; unit tests on `cite_metrics` |
| T-16-23 | Tampering | manual verdict column overwritten by a re-run or by the judge | mitigate | `_load_existing_verdicts` carries the cells over; the judge writes only `judge_verdict` / `judge_comment`; test |
| T-16-24 | Tampering | threshold tuned on the control set to hide false refusals | mitigate | the subcommand takes the threshold from `resolve_threshold` / run_meta and this plan changes no threshold constant; grep gate |
| T-16-SC | Tampering | package installs | accept | no packages are installed |
</threat_model>
