<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM -> MCP tools | `staged`, `ref`, `path` and `count` are chosen by a language model and may be shaped by untrusted text it has read |
| MCP server -> git | Each tool starts git with the user's rights; repository configuration can name external programs |
| MCP server -> LLM context | Diff, file names and commit subjects are returned to the model as tool output |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
