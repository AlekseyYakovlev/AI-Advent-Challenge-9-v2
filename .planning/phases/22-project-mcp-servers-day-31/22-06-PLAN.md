| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-22-33 | Repudiation | Full-suite result taken while another plan was still writing documents and tests | mitigate | The full `pytest tests/` run is made by Task 3 of this plan, after `22-04-SUMMARY.md` and `22-05-SUMMARY.md` exist; `Suite: passed` requires a clean summary line, checked by the verify command |

| T-22-31 | Tampering | Tampered binary | mitigate | User follows the documented SHA-256 comparison; the record stores the exe version and hash for later comparison |
| T-22-32 | Elevation of Privilege | Token with write rights kept in the app's database | accept | Accepted by D-17 (reserve for later Pull Request days); the value is stored per user and never returned by the API; read-only rests on the flag, as documented |
