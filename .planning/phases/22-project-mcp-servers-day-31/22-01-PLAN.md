## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM -> MCP server | Tool arguments (`path`, `ref`) are chosen by a language model that may be steered by text in files, diffs or commit messages; they are untrusted input |
| MCP server -> git | The server starts a real `git` process with the user's rights in the user's repository |
| repository config -> git | `.git/config` and inherited `GIT_*` variables can make git run programs or look at another directory |
