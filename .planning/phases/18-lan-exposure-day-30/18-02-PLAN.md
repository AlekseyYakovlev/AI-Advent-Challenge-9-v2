<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser on any site -> Agent REST (:AGENT_PORT) | `Origin` and `Host` headers are attacker-influenced; the session cookie is sent automatically by the browser |
| Browser on any site -> Agent WebSocket | Browsers do not apply CORS to WebSocket handshakes; only the server-side Origin check stops cross-site WebSocket hijacking |
| LAN client -> Agent | In LAN mode every machine on the network reaches the same endpoints |
