<objective>
Deliver the first working vertical slice of authentication: a real user opens `ui/static/login.html`, submits a username and password, the Agent process verifies it against an argon2id hash in a new `user` table, inserts a real `session` row, and returns an HTTP-only session cookie that `GET /api/v1/auth/me` accepts on the next request.

Purpose: This is the spine of the Walking Skeleton — login page → REST route → DB write → DB read → cookie → authenticated UI. Every later plan in this phase hangs off the `User`/`Session` tables and the `get_current_user` dependency created here.

Output: `shared/auth.py`, `User`/`Session` tables, `agent/dependencies.py`, three auth routes (`login`, `logout`, `me`), a tightened CORS allowlist, `ui/static/login.html`, and a `credentials: 'include'` + 401-redirect-capable `app.js`.
</objective>

## Phase Goal

**As a** user of this local AI chat app, **I want to** log in with a username and password and stay logged in across page reloads, **so that** my chats, settings and memory are mine and not shared with everyone who opens the app.
