<objective>
Turn the session cookie into real access control. Every pre-existing REST endpoint in `agent/main.py` gains `Depends(get_current_user)` AND a `user_id` filter, so a logged-in user sees only their own chats and settings and cannot reach another user's rows by guessing an id. The whole pre-existing test suite is repaired in the same slice so the phase never ends red.

Purpose: Plans 01 and 02 built the lock and gave every row an owner; this plan actually locks the doors. Without it, "logged in" is decorative — any browser could still `GET /api/v1/chats` with no cookie and read everything.

Output: authenticated + owner-scoped `agent/main.py` routes, an owner-scoped global-settings fallback in `agent/context_engine.py`, a `login_test_client` sync helper in `tests/conftest.py`, a new `tests/test_scoping.py`, and eight repaired pre-existing test files.
</objective>

## Phase Goal

**As a** user of this local AI chat app, **I want to** log in with a username and password and stay logged in across page reloads, **so that** my chats, settings and memory are mine and not shared with everyone who opens the app.
