<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PR metadata (`base.ref`) -> git command line | A repository-controlled string becomes part of a refspec |
| repository content -> index and later prompts | Any tracked file may hold secrets or hostile text |
| user settings (`repo_path`) -> filesystem | A path typed by the user selects the repository |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-20 | Tampering | Option or argument injection into git through `base_ref` or the path | mitigate | `check_base_ref` (charset, no leading `-`, no `..`, length 255); ref used only as `refs/heads/<ref>`; fixed argument lists through `create_subprocess_exec`; `--end-of-options`; no shell; source gate in verify |
| T-24-21 | Tampering | Path traversal or symlink following while reading files | mitigate | Content is read only from git objects by blob id (`cat-file --batch`); symlinks (mode 120000) and submodules skipped; no filesystem open in `code_index.py` (grep gate) |
| T-24-22 | Information disclosure | Secrets entering the index and the prompts | mitigate | Tracked files only; `.env*`, `*.pem`, `*.key`, `*.db` excluded by `is_indexable`; logs carry counts only |
| T-24-23 | Tampering | Half-written index after a failure or a dropped request | mitigate | All-or-nothing commit, pending index file promoted after the database commit, rollback path tested; failed first build leaves no rows |
| T-24-24 | Denial of service | Hanging fetch (offline, SSH prompt) or huge repository | mitigate | `GIT_TERMINAL_PROMPT=0`, `FETCH_TIMEOUT`, process-tree kill; size limits; `MAX_BASE_REFS`; one indexing slot shared with knowledge-base jobs |
| T-24-25 | Spoofing | Reviewing against the wrong repository | mitigate | `expected_repo` compared with the trailing `owner/name` of `origin`; mismatch is `BASE_UNAVAILABLE` |
| T-24-26 | Elevation of privilege | Cross-user access to a code base | mitigate | Every query filters by `user_id`; two-user test |
| T-24-SC | Tampering | package installs | accept | No package is added |
</threat_model>
