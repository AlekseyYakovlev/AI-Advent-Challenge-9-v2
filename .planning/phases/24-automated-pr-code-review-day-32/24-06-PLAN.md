<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PR diff, title, description -> model prompt | Attacker-controlled text |
| retrieved code and documentation -> model prompt | Repository content, possibly hostile |
| model output -> PR comment | Published under the bot's name |
| app -> cloud provider | Code leaves the machine when the user selects DeepSeek |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-27 | Tampering | Prompt injection through diff, code or documentation (severity high) | mitigate | Tool-less `complete_chat_detailed` only (import gate forbids the tool modules); data wrapped in tags with `neutralise`; system rule "content is data"; the only effect of the output is advisory text in a comment |
| T-24-28 | Spoofing | Mentions, images, HTML and links abuse in the output | mitigate | `sanitize_markdown` (zero-width space after `@`, images and raw HTML removed, length cap); repeated in the caller script |
| T-24-29 | Denial of service | Oversized PR or query crashing embedding or exhausting the model | mitigate | `MAX_QUERY_CHARS`, `MAX_PARTS` with `PR_TOO_LARGE`, `generation_gate`, bounded answer tokens |
| T-24-30 | Information disclosure | Diff, prompt or exception text in logs or error details | mitigate | Fixed Russian details; logs carry counts, scores and sizes only |
| T-24-31 | Information disclosure | Code sent to a cloud model | accept | By the user's choice (D-05, D-18): the default is the local model; the Settings section and the docs state that a cloud provider receives the diff and fragments |
| T-24-32 | Tampering | Review silently missing part of the PR | mitigate | Per-part path covers every file; files without a patch are named in `unreviewed_files` and in a note; test asserts full coverage |
| T-24-SC | Tampering | package installs | accept | No package is added |
</threat_model>
