<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM output -> dispatcher | Tool names/arguments produced by the model are untrusted, and no user is present to notice misuse |
| MCP tool results -> LLM context | File/remote content read by MCP may contain prompt injection |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-10 | Elevation of privilege | dispatch_tool_calls in headless runs | mitigate | allowed_tools allowlist enforced in the dispatcher (not only schema filtering); unknown-tool result for any non-allowlisted built-in; test with hallucinated create_task |
| T-08-11 | Elevation of privilege | job spawning/cancelling jobs | mitigate | schedule_task / list_scheduled_tasks / cancel_scheduled_task are outside HEADLESS_TOOL_ALLOWLIST (allowlist, so future tools are excluded by default) (D-04) |
| T-08-12 | Elevation of privilege | prompt injection via MCP content -> destructive MCP tool | accept | Jobs are user-authored; round cap + engine timeout bound the blast radius; destructive-tool gating is backlog 999.1 (Day 20, deferred by the user) |
| T-08-13 | Information disclosure | logs | mitigate | Log ids, counts and exception type names only; never prompt, tool args or results |
| T-08-14 | Denial of service | runaway tool loop | mitigate | Existing MAX_TOOL_ROUNDS cap and loop detection reused unchanged; overall timeout added by 08-04 |
</threat_model>
