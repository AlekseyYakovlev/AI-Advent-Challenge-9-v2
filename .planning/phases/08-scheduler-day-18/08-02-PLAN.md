## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> /ws/events | Untrusted handshake (cookie, Origin) crosses into the Agent |
| scheduler/REST -> hub -> socket | Per-user data (run status, titles) leaves the process |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-05 | Spoofing | ws_events handshake | mitigate | get_current_user_ws on the HTTP-only session cookie before accept; close 1008 on failure |
| T-08-06 | Tampering (CSWSH) | ws_events Origin | mitigate | Reuse ws._validate_origin allowlist before accept; close 1008 |
| T-08-07 | Information disclosure | EventHub fan-out | mitigate | Subscriptions keyed by authenticated user.id; publish(user_id, ...) only touches that user's queues; isolation test with sentinel frame |
| T-08-08 | Denial of service | slow/dead browser | mitigate | Bounded queue (100) with drop-oldest, sync non-blocking publish, one writer task per socket, receive timeout loop |
| T-08-09 | Elevation (session revoked mid-socket) | long-lived socket | accept | Same trust model as /ws/chat (auth at handshake); frames only carry the same user's own data |
</threat_model>
