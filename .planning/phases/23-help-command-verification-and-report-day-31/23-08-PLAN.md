## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| run results -> committed report | Model answers, tool outputs and metadata are published in the repository |
| script -> DeepSeek judge | Questions, references and answers are sent to an external provider with the user's key |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-41 | Information Disclosure | DeepSeek key or API key in `eval_out/day31/` or the report | mitigate | Key only in memory and request headers; all saved text scrubbed; verify commands scan the outputs and the report for key-shaped strings |
| T-23-42 | Repudiation | A run that did not happen, or a failed question, presented as passed | mitigate | Statuses come from `run_meta.json` and `judge_meta.json`; verify command requires the report to state a not-run model; failed questions are kept with answers (D-21) |
| T-23-43 | Tampering | Answers or the control set adjusted after the run | mitigate | Fixture hash checked by `judge` and `summary`; fixture diff must be empty; report values are taken from the saved files; one run, no reruns to improve answers |
| T-23-44 | Spoofing | Judge verdict overstated as independent | mitigate | The report states that judge and answering model share a provider on the DeepSeek run (D-19) and shows automatic checks next to the verdict |
| T-23-45 | Information Disclosure | Git tool output (paths, commit subjects) of the real repository published | accept | It is the repository's own metadata, published in the same repository |
| T-23-46 | Denial of Service | Run colliding with the user's app | mitigate | Same isolation as Plan 23-05 (ports 18000/18001, `assert_isolated`, teardown of started processes only) |
| T-23-SC | Tampering | Package installs | accept | No package is installed by this plan |
</threat_model>
