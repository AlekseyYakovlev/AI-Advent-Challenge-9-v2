<objective>
Make retrieval history-aware: load the recent turns of the active branch and the task memory, condense the follow-up into a standalone query on the chat's own model, search both queries and merge, with the gate unchanged.

Purpose: RCHAT-03 and success criterion 3. A follow-up such as «а за повторное?» embeds far from any chunk; only a condensed query that carries the goal and the terms retrieves the repeat-offence fragment.
Output: condense prompt and validation in `agent/rag_rank.py`, `condense_query` in `agent/rag_llm.py`, `HistoryContext` and the stage branch in `agent/rag_pipeline.py`, the history loader and the new `prepare_rag_turn` input in `agent/rag_turn.py`, tests. The call site in `agent/ws.py` is wired in plan 17-06; until then `parent_id` defaults to None and behaviour is unchanged.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored dialog and task memory -> condensing prompt | earlier user text and model answers are replayed into an LLM prompt |
| model output -> search query | the condensed query is embedded and searched |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-10 | Tampering | prompt injection through history or memory text closing `<history>` / `<memory>` / `<question>` | mitigate | every inserted text goes through `neutralize_data_tags`; `CONDENSE_SYSTEM_PROMPT` states the tags hold data; test with closing tags in a pair |
| T-17-11 | Tampering | query drift: the condensed query replaces what the user asked (PITFALLS 18) | mitigate | the raw question is always searched too and results merge by best cosine; digit-subset rule; bad output falls back to the raw question (D-14) |
| T-17-12 | Elevation of privilege | condensing used to slip past the «не знаю» gate | mitigate | the gate verdict is computed after the merge with the unchanged threshold; tests for both gate outcomes |
| T-17-13 | Denial of service | long history inflating the prompt or stalling the turn | mitigate | `history_turns` clamped to 0..10, answers trimmed to 300 characters, `CONDENSE_MAX_TOKENS = 160`, `RAG_LLM_STAGE_TIMEOUT`, fail-soft skip |
| T-17-14 | Information disclosure | another chat's messages entering the history | mitigate | the walk follows `parent_id` from this turn's own parent only; sibling-branch test |
| T-17-15 | Information disclosure | question or history text in logs | mitigate | log lines carry ids, counts and error type only |
| T-17-SC | Tampering | package installs | accept | this plan installs no package |
</threat_model>
