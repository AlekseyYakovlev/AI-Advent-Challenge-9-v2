<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user message and model answer -> extraction call inside the turn | untrusted text goes to an extra LLM call while the per-chat lock is held |
| stored task memory -> system prompt | user-stated text is replayed as part of the system prompt on every turn |
| turn result -> client | the snapshot is sent in the `done` frame and stored per message |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-27 | Elevation of privilege | stored user text in the system prompt acting as instructions (prompt injection that persists across turns) | mitigate | lines are labelled as the user's task memory, item and goal lengths are capped (plan 17-01), only user-stated content is stored (D-04), the user can see, delete and reset every item (plans 17-04, 17-07); residual risk accepted for a single-user local app where the user is the only author of the text |
| T-17-28 | Tampering | memory row committed without its message, or the reverse | mitigate | the update only stages; one commit in `_persist_assistant_message`; gated-path failure test proves the rollback removes the staged row |
| T-17-29 | Denial of service | the extra call stalling the turn while the chat lock is held | mitigate | `TASK_MEMORY_TIMEOUT` (30 s), `EXTRACT_MAX_TOKENS`, fail-soft result; a disconnect cancels the task as for the existing invariant call |
| T-17-30 | Information disclosure | fragments or law text sent to the extraction call or stored in memory | mitigate | only the user text and the clean stored answer are passed; test asserts the request has no fragment block marker |
| T-17-31 | Repudiation | a failed extraction looking like a successful update | mitigate | snapshot `failed: true`, log event `task_memory_update_failed`; the UI and the report show it (plans 17-07, 17-08) |
| T-17-32 | Information disclosure | memory text in logs | mitigate | no new log line carries message or memory text |
| T-17-SC | Tampering | package installs | accept | this plan installs no package |
</threat_model>
