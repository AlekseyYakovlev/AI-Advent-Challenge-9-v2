    Functions:
    tokenize(text): lowercase, find word tokens with the word-character regex, drop tokens shorter than MIN_TOKEN_LEN, tokens in STOPWORDS and tokens that are only digits.
    stems(text): set of the first STEM_LEN characters of each token.
    article_numbers(text): dotted numbers found anywhere plus numbers captured by ARTICLE_WORD_RE, in order of first appearance, de-duplicated.
    parse_article(text): the last ARTICLE_IN_SECTION_RE match in the string (deepest article), or None; same behaviour as scripts/rag_eval.py::parse_article.
    lexical_score(query, chunk): overlap = size of the intersection of query stems and the stems of section + " " + text, divided by the number of query stems (0.0 when the query has no stems). article_match = 1.0 when any query article number equals parse_article(section) or parse_article(title); else ARTICLE_TEXT_ONLY_SCORE when any query article number occurs in the chunk text as a whole number token (not as a prefix of a longer number: "12.9" must not match "12.91" or "112.9"); else 0.0.     lexical_rerank(query, chunks): compute lexical_score for every chunk; normalise the chunks' "score" values with min-max where a spread below MINMAX_EPSILON maps every value to 1.0 (research Pitfall 4); fused = FUSION_COSINE_WEIGHT * normalised cosine + FUSION_LEXICAL_WEIGHT * lexical; return (order, lex_scores) where order is the list of input indices sorted by fused descending with a stable sort, and lex_scores is aligned with the input list and rounded to 4 decimals. With fewer than 2 chunks the order is the identity. The input list and its dicts are not modified.
    rrf_order(vector_ids, fts_ids): score of an id = sum over the lists that contain it of 1 / (RRF_K + rank), rank starting at 1; return all distinct ids sorted by score descending; ties broken by position in vector_ids (ids absent from it last), then position in fts_ids.
    build_fts_query(question): terms = each dotted article number wrapped in double quotes, then for each token from tokenize(question) the first STEM_LEN characters wrapped in double quotes followed by an asterisk; de-duplicate preserving order; join with " OR "; return None when there are no terms. Because tokens come only from the word-character regex and the dotted-number regex, no user-supplied quote or operator can reach the output.
    choose_threshold(gold_scores, ooc_top1): when either list is empty return (0.0, {"separable": False, "method": "none"}). Otherwise stats holds gold_min, gold_median, gold_max, ooc_min, ooc_median, ooc_max (statistics.median), n_gold, n_ooc. When max(ooc_top1) < min(gold_scores): threshold = midpoint of those two values rounded half-up to 2 decimals (use math.floor(x * 100 + 0.5) / 100, not the built-in round, which rounds half to even), separable True, method "midpoint", youden_j 1.0. Otherwise evaluate every distinct value of both lists as a candidate T with J = share of gold_scores >= T minus share of ooc_top1 >= T, pick the T with the highest J (lowest T on ties, so answerable chunks are kept), round it the same way, separable False, method "youden", youden_j rounded to 4 decimals.
