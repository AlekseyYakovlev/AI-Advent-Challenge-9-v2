## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WebSocket message -> RAG pre-step | user text triggers retrieval and optional LLM stage calls |
| RAG payload -> SQLite / browser | trace persisted on the assistant message and pushed in the done frame |
| outbound prompt assembly | instruction text and user text are merged into one user message |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-22 | Information disclosure | Message.rag_sources / done.rag | mitigate | trace is metadata only; test asserts seeded chunk text is absent from the stored JSON; chunk text stays behind the ownership-checked snippet route (Phase 14) |
| T-15-23 | Information disclosure | rag_turn logging | mitigate | _log emits ids, counts and codes only; query and rewritten query are never logged |
| T-15-24 | Elevation of privilege | KB access in the turn | mitigate | prepare_rag_turn keeps _load_kb (foreign KB counts as missing) before building the pipeline config; pipeline receives only that KB object |
| T-15-25 | Tampering | no-fragments note | mitigate | fixed constant text merged only into the outbound copy; stored user message unchanged (test); user text stays after the QUESTION_PREFIX like in merge_rag_block |
| T-15-26 | Denial of service | pre-stream latency under the chat lock | mitigate | stage calls bounded by RAG_LLM_STAGE_TIMEOUT and RAG_EMBED_TIMEOUT; all optional stages fail-soft; default config makes no extra LLM call (D-03) |
| T-15-27 | Spoofing | provider used for stage calls | mitigate | the client is the one resolve_client returned for this user and provider_id; no separate provider lookup (D-11) |
| T-15-SC | Tampering | package installs | accept | no packages are installed in this phase |
</threat_model>
