- `classifyDiffLine(line, inHunk)`: Research Pattern 8 state machine: `'diff --git '` → meta, inHunk false; when not inHunk, lines starting `'--- '`, `'+++ '`, `'index '`, `'new file mode'`, `'deleted file mode'` → meta; `'@@'` → hunk, inHunk true; not inHunk → context (summary line, stat lines, truncation marker); in hunk: `'+'` → added, `'-'` → removed, `'\\'` → meta, else context. Returns `{ kind, inHunk }`.
- `diffLineCounts(text)`: walks lines with classifyDiffLine and counts added/removed.
- `diffSummarySuffix(evt)`: when `evt.truncated`, match the first line of `evt.result` against `/\(\+(\d+) -(\d+)\)/`; no match → return ''; otherwise use the matched counts; when not truncated use diffLineCounts. ' ' : line` (so empty rows keep their height). Drop one trailing empty line produced by a final "\n". Never use innerHTML or insertAdjacentHTML.
