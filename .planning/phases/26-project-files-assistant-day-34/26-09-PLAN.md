- `class ToolInputError(ValueError)` is the MCP isError signal. Every refusal raises it with an English reason and fix.

- `def resolve_inside_root(root_real: str, raw: str) -> str` (L274). It validates the raw path, computes `os.path.realpath(os.path.join(root_real, raw))`, checks `commonpath` against the root and returns the root-relative path with `/` separators (or `"."`). It raises `ToolInputError("path must stay inside the repository root; ...")` when the path escapes.
- `def _normalise_path(path: str | None) -> str | None` returns `resolve_inside_root(get_config().root, path)` or None.
- `async def visible_paths(rel: str | None = None) -> list[str]` runs `git ls-files --cached --others --exclude-standard -z [-- rel]` and returns `/`-separated relative paths.
- `async def require_visible_file(rel: str) -> str` (L683) raises when `rel == "."`, when rel is not in `visible_paths(rel)` or when it is not a file. Otherwise it returns `os.path.join(root, rel)`. `read_file` calls `_normalise_path(path)` first, so read_file already resolves symlinks to their target.
- `async def search_text(...)` (L769) runs `git grep -n -I --untracked --exclude-standard` and parses each output line with `line.split(":", 2)` into `(path, lineno, text)`. It counts `total` and `files` and keeps the first MAX_SEARCH_HITS hits.
- `async def find_usages(symbol: str, path: str | None = None) -> str` (L915). The loop is `for item in py_files:` with `absolute = os.path.join(cfg.root, item)`, then getsize > MAX_PARSE_BYTES, open, decode_text and ast.parse. On error it does `skipped += 1`. The summary appends `f"; {skipped} files skipped (syntax errors)"`.
- `async def check_write_target(path: str | None) -> tuple[str, str]` (L1017). Per `/` part it checks `bare = part.rstrip(". ")`. If `bare.casefold() == ".git" or _SHORT_GIT.match(bare)` it raises "writing inside .git is not allowed; choose a path in the working tree". The reserved device names check runs next.
