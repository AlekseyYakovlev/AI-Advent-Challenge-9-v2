<objective>
Prepare `agent/ws.py` for reuse by the HTTP chat endpoint: extract the turn from the lock
wrapper, fix the leaf-pointer bug on failed turns, and make the cause of an LLM failure
machine-readable.

Purpose: HCHAT-02 requires the HTTP turn to be the same code as the WebSocket turn, and
HCHAT-03 requires telling "LM Studio is not running" (503) from other model errors (502).
Output: three new helpers in `agent/ws.py`, an unchanged public WebSocket behaviour except
the bug fix below, and a regression test file.

IMPORTANT, behaviour change for WebSocket (pre-existing bug, RESEARCH Pitfall 1, reproduced
by the researcher): today, deleting the user message after a failed turn makes the database
set `Chat.current_leaf_message_id` to NULL (`ON DELETE SET NULL`), so the next message starts
a new root and the earlier conversation disappears from the tree and from the model context.
This plan fixes it for both transports. It is a bug fix riding along with the phase; state it
in the SUMMARY so the user sees it.
</objective>
