<objective>
Add the plain-HTTP chat endpoint: one POST into an existing chat, the whole reply back as one
JSON body with statistics, stored in the normal message tree through the same turn code as
WebSocket.

Purpose: HCHAT-01, HCHAT-02, HCHAT-03.
Output: `agent/http_chat.py`, `apply_chat_kb` in `agent/rag_api.py`, request and response
schemas, router registration, and two test files (including the HTTP side of the
leaf-restore regression).

Out of scope here (Phase 20): rate limiting, 429 with Retry-After, a concurrency cap or
queue. Do not add any of them to this endpoint. Deferred ideas that must not appear: SSE
streaming, stateless chat, a per-request MCP switch, an "API" marker on messages.
</objective>
