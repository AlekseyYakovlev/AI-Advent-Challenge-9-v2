## Trust Boundaries

| Boundary | Description |
|----------|-------------|

| e2e script -> real credentials | The environment may hold a real DeepSeek key and a real `.env` |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-19-37 | Denial of service | the user's running app on 8000/8001 | high | mitigate | The copy uses 18000/18001 only; preflight exits 2 when a needed port is busy; only processes started by the script are stopped; acceptance criteria forbid `8000`/`8001` literals |
| T-19-38 | Tampering | the user's `app.db` and `.env` | high | mitigate | Scratch `DB_PATH`, a copied tree, no write to the repository `.env`; `git status` checked after the run |
| T-19-39 | Information disclosure | real provider keys leaving the machine | medium | mitigate | `DEEPSEEK_API_KEY` is forced empty for the copy and the only provider is the local stub |
| T-19-40 | Information disclosure | the e2e API key in artifacts | low | accept | The key belongs to a scratch database that is discarded; it is revoked at the end of the run (R1) |
| T-19-41 | Spoofing | a check that passes without exercising the key | medium | mitigate | The HTTP client has no cookie jar; H2 asserts 403 on a cookie-only route and H5/R2 assert 401, which can only happen when the key alone is evaluated |
| T-19-SC | Tampering | package installs | low | accept | No package is installed; a missing Playwright ends the run with exit 4 and is recorded as BLOCKED |
