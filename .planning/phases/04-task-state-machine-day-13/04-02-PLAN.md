## Trust Boundaries

| Boundary | Description |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-08 | Tampering | `agent/tasks.py::transition_task` (LLM-supplied `task_id`) | mitigate | `_get_owned_task` loads the row and raises `TaskNotFoundError` unless `task.chat_id == chat_id and task.user_id == user_id`, before any mutation. `agent/tools.py::_SCOPE_KEYS` only guards `chat_id`/`user_id` argument keys and provides no protection here. Covered by `test_transition_task_other_chats_task_is_rejected` and `test_transition_task_other_users_task_is_rejected`. |
| T-04-09 | Information Disclosure | `TaskNotFoundError` message | mitigate | The tool result says only "task {id} not found in this chat" — it does not distinguish "does not exist" from "belongs to someone else", mirroring `_get_chat_or_404`'s 404-never-403 policy so the LLM (and anyone prompt-injecting it) cannot enumerate task ids. |
| T-04-10 | Elevation of Privilege | `transition_task` reaching the `cancelled` terminal state | mitigate | `LlmTaskState` omits `CANCELLED`, so `build_tool_schemas()` never advertises it and Pydantic rejects it at validation time before the handler runs (D-07). Covered by `test_transition_task_rejects_cancelled_state`. |
| T-04-11 | Denial of Service | `note` field length | mitigate | `TASK_NOTE_MAX_LENGTH = 2_000` enforced by `TransitionTaskArgs` before the DB write. |
| T-04-12 | Tampering | Timeline rendering in `ui/static/app.js` | mitigate | `renderTaskHistory` uses `document.createElement` + `textContent` exclusively; the LLM-authored `note` is never parsed as HTML. |
| T-04-13 | Repudiation | Transition audit trail | mitigate | Every accepted transition appends an immutable `TaskTransition` row with `from_state`, `to_state`, `note` and `created_at`, committed atomically with the `Task.state` change. |

| T-04-SC | Tampering | npm/pip/cargo installs | accept | No new packages in this phase; `requirements.txt` unchanged. |
