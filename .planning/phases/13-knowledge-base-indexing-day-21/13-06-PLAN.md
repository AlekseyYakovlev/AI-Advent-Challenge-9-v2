         -> 409 "Поиск доступен после завершения индексации" when status != ready; 404 foreign; 503 LM Studio down; 422 EmbeddingError message

POST   /api/v1/kb/embedding-check JSON {"model": str} -> 200 {"model": str, "dim": int} | 422 Russian guard message | 503 LM Studio down

| T-13-25 | Tampering | duplicate files | mitigate | SHA-256 while streaming rejects the upload (D-05) + DB unique (kb_id, sha256) |
