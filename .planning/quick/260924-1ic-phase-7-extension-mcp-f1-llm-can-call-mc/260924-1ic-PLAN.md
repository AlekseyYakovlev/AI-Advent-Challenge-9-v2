<objective>
Let the LLM call MCP tools from a chat turn (MCP-F1). The tools of the current user's connected and enabled MCP servers are merged into the per-turn tool list under collision-safe namespaced names. Calls go to the live ClientSession with a timeout and a result-size cap, and every failure comes back as a tool result instead of a crash. The UI shows each call as a collapsed card. The work is verified with pytest (fixture server), with a port-free pytest check against the real filesystem.exe, and with a Playwright run against the real filesystem.exe on an isolated instance.

Purpose: user feedback on Phase 7 ("Не получается вызвать использование инструментов из чата"). Today the model says it has no filesystem tools even when filesystem.exe is connected.
Output: agent/mcp_tools.py (new), changes to tools.py/ws.py/mcp_client.py/schemas.py/config.py/app.js, three new test files, a Playwright verification script, and docs/requirements updates.

Plan size note: this plan deliberately has 4 tasks (above the usual 2-3). The feature is one vertical slice, and the docs commit (Task 3) is split from the real-server verification (Task 4) so that a Playwright run blocked by busy ports never holds up the docs commit.
</objective>
