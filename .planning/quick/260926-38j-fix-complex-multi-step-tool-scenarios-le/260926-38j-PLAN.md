<objective>
Make multi-step tool requests work end to end with the local LM Studio model (filesystem MCP + gitlab-mcp). Two example requests:
(A) "В папке Sandbox создай файл 12.txt, потом создай файл 13.txt, в оба файла запиши их названия и текущую дату и время. После этого отобрази содержимое папки."

Purpose: logs and chat 35 in app.db show five separate root causes:
1. Tool calls leaked as text, and tool-call deltas dropped on finish_reason "stop".
2. The model announces a step and then stops, or gives up after one tool error.
3. An empty reply is saved after tool rounds, and the model mixes up local folders with remote repo paths.
4. There is no clock source.
5. MAX_TOOL_ROUNDS=5 is too low.

Output: fixes in llm_client / a new text_tool_calls module / tool_guard / ws, tests for each fix, and an honest check against the real model.
