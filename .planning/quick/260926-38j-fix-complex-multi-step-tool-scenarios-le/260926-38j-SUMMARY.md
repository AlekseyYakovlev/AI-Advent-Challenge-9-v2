# Quick 260926-38j: Multi-step tool scenarios with the local model

Text-written tool calls are now executed, announce-and-stop replies and single MCP errors get one bounded nudge, empty post-tool replies are replaced by a deterministic summary, and the system message carries the local clock plus a short multi-step hint.

## Changes per root cause

1. **Tool calls leaked as text / dropped deltas.** New `agent/text_tool_calls.py` (`TextToolCallFilter`, `parse_text_tool_calls`, `resolve_tool_name`) handles hermes JSON and qwen XML (missing closers, alias names, typed params, unknown/ambiguous names dropped). `_ReplyFilter` in ws.py chains it into `TraceLeakFilter` for the first tools stream, the action-claim retry and every follow-up; markup is never emitted or saved. `_parse_sse_stream_with_tools` now flushes accumulated tool_calls at stream end (finish_reason stop/length, `[DONE]` only, EOF), once.
2. **Announce-and-stop / give up after one error.** `looks_like_action_announcement` plus `ACTION_ANNOUNCE_REMINDER` (one nudge before round 1 and one between rounds) and `TOOL_ERROR_REMINDER` (one nudge after a last-round MCP failure). Nudge answers are streamed with tools and a lazy "\n\n" separator. Flags live on `_ToolRoundsResult`.
3. **Empty reply after tools / local-vs-remote confusion.** `build_tool_fallback_summary` (RU if user text has Cyrillic) is sent as one token frame and saved when the post-tool text is empty. `MULTI_STEP_TOOL_HINT` covers local vs remote paths and the commit flow.
4. **No clock.** `build_clock_line` appended to every turn's system message.
5. **Round cap.** `MAX_TOOL_ROUNDS = 10`.

System message layout: `base + "\n\n" + clock [+ "\n\n" + hint + "\n\n" + TOOL_USE_RULE]`; the rule stays the last removable suffix.
