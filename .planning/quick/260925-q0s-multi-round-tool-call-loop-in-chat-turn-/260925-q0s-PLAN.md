<objective>
Replace the single tool-call round in `agent/ws.py::_handle_chat_message` with a bounded loop of up to `MAX_TOOL_ROUNDS` rounds. Follow-up streams keep `tools=`, so the model can chain steps (for example get_file_contents followed by write_file) instead of printing a raw "<tool_call>" text.

Purpose: a real model check (qwen3.5-9b + filesystem/GitLab MCP) showed that any second step was lost, because the follow-up request had no `tools`.
Output: the loop helpers in ws.py, the `MAX_TOOL_ROUNDS` constant, a new test file, and one adjusted existing test.
</objective>
