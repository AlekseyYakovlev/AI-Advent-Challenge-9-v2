<objective>
Implement the locked design in 260924-2n8-TASK.md: when a chat turn builds its MCP toolset, lazily connect the chat owner's
ENABLED MCP servers that have no live session and no remembered failure, so the LLM can use their tools without the user
pressing "Подключить" in Settings first.

Purpose: the model can only call tools present in the tool list, and a server's tool list is only known after connecting,
so the connect has to happen at turn start (inside `build_mcp_toolset`, called by `agent/ws.py::_load_mcp_toolset`).
Output: `ensure_connected` in agent/mcp_client.py, auto-connect fan-out in agent/mcp_tools.py, `MCP_AUTO_CONNECT` setting,
unit + WS + real filesystem.exe tests, short doc paragraphs. The design is decided; do not redesign it.
</objective>
