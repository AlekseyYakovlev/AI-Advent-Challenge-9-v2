Готово. ADR создан на русском языке по структуре «Контекст → Решение → Последствия».

Кратко о содержании:
- **Контекст** — локальное приложение на Windows/Python 3.13, запрет Docker, `multiprocessing`, брокеров; IPC только REST + WebSocket; разный профиль нагрузки у UI и LLM-части.
- **Решение** — два процесса: UI (порт 8000: статика + supervisor) и Agent (порт 8001: REST, WebSocket, LLM, MCP, RAG, планировщик); запуск через `asyncio.create_subprocess_exec`, health-check каждые 3 с и проверка готовности по `/health` 200 + `/debug/routes` 401, очистка осиротевших процессов через `psutil`, общий `BIND_HOST`, браузер обращается к Agent напрямую, единое правило Origin.
- **Последствия** — изоляция отказов и независимый перезапуск; при этом усложнение жизненного цикла, жёсткая остановка на Windows, потеря in-memory состояния при рестарте Agent, две сетевые точки входа, распределённая диагностика и риск рассинхронизации `shared/`.
