## doc-api (docs)

Вопрос: Каким HTTP-запросом отправить сообщение в чат и как при этом авторизоваться?
Ожидаемый источник: docs/API_SPEC.md; ожидаемый инструмент: none

### local
- Ответ:
  > Для отправки сообщения в чат через HTTP используется POST-запрос к эндпоинту `/api/v1/chats/{chat_id}/messages`.
  > 
  > **Авторизация:**
  > Через заголовок `Authorization: Bearer <your key>` [1][3]
  > 
  > **Пример запроса:**
  > ```bash
  > curl -s -X POST http://127.0.0.1:8001/api/v1/chats/<chat_id>/messages \
  >   -H "Authorization: Bearer <your key>" -H "Content-Type: application/json" \
  >   -d '{"content": "Привет", "model": "<model>"}'
  > ```
  > 
  > **Тело запроса:**
  > - `content` — текст сообщения (обязательно) [3]
  > - `model` — id модели (обязательно) [3]
  > - `kb_id` — опционально, id базы знаний для RAG [1][3]
  > 
  > **Важно:**
  > - Используйте порт AGENT_PORT (8001 по умолчанию), а не UI порт [1]
  > - Content-Type должен быть `application/json`, иначе вернётся ошибка 415 [3]
  > - Чат создаётся через `POST /api/v1/chats` и нужно запомнить его `id` [2]
- Источники: docs/USER_GUIDE.md, docs/API_SPEC.md
- Вызовы инструментов: нет
- Автопроверки: источник совпал: да; нужный инструмент вызван: да; отказ: нет
- Судья: верно. Ответ верно указывает метод и эндпоинт, порт Agent (8001), авторизацию через заголовок Bearer с API-ключом и обязательные поля тела content и model, а также опциональный kb_id.
